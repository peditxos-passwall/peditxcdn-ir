# DNS Gaming

سیستم‌عامل OpenWrt خود را به یک کنسول مدیریتی قدرتمند و زیبا تبدیل کنید.

## 🚀 ویژگی‌ها

- **پوسته‌های مدرن** - رابط کاربری جذاب و کاملاً ریسپانسیو
- **ابزارهای قدرتمند** - نصب Passwall، Xray و ابزارهای تحریم‌گذر
- **بهینه‌سازی شده** - تنظیمات بهینه کرنل برای حداکثر پایداری
- **استور اختصاصی** - مدیریت کامل بدون نیاز به نرم‌افزار جانبی

## 📦 نصب و راه‌اندازی

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# بیلد برای تولید
npm run build

# پیش‌نمایش بیلد
npm run preview
```
